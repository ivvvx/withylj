适配策略 — Tailwind CSS 断点

断点 屏幕 适配行为
默认（移动优先） <768px 汉堡菜单，2 列卡片，单列时间线，图片全宽
md (≥768px) 平板 顶部导航展开，3 列卡片
lg (≥1024px) 桌面 内容区最大宽度 960px 居中，更大的 Hero 区域
⚠️ 关键原则：
• 图片始终用 max-width: 100%; height: auto，不会溢出
• 用 Tailwind 的 grid-cols-2 md:grid-cols-3 控制列数
• 字体用 clamp() 或 Tailwind 响应式类，不会在小屏过大
• 开发时先用浏览器 DevTools 的手机模拟器测试，再在真机上确认
